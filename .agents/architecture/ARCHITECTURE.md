## Architecture Decision Records (ADR)

All agents MUST read and follow:
[`docs/agent-instructions/adr.md`](docs/agent-instructions/adr.md)

This policy is mandatory for every task.

- Before implementation, review relevant existing ADRs.
- After implementation, perform an ADR impact review.
- Create ADRs for new significant architectural decisions.
- Update ADRs when existing decisions evolve.
- Supersede ADRs when decisions are replaced.
- Keep the ADR index synchronized.
- Include ADR review results in the final task report.

**Never consider an architecture-changing task complete until its ADR documentation is synchronized.**
